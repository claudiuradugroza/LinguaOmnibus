    Chapter 01

    Welcome to Lingua Omnibus

    By the end of this tutorial, you will have written three working programs in two natural languages, seen that they produce byte-identical compiled output, queried an embedded database, written and run a test, and understood how to add a new natural language as a data file.

    You do not need to know English to program in Lingua Omnibus. Every example is given in English and Romanian, with additional languages where they help.

    Before we start

    Lingua Omnibus is at spec-0.1. Code here is written against the normative specification (SPEC-00, 01, 02) and compiles with the reference implementation that is under construction. Where the tooling is not yet available, sections are marked spec-preview. Everything shown will work exactly as written once M1 ships.

    What you will build

    • A Hello, World program in two languages that produces the same binary
    • A factorial function, in three languages
    • A small database application using LinguaDB
    • A unit test in two languages

    Chapter 03

    Hello, World

    The English version

    Create src/main.lo:

    🇬🇧 ENsrc/main.lo
    #lingua: EN

function main() returns Unit:
    print("Hello, world!")

    Run it:

    bash
    loc run src/main.lo
    ▶ output
    Hello, world!

    The Romanian version

    Change #lingua: EN to #lingua: RO and rewrite:

    🇷🇴 ROsrc/main.lo
    #lingua: RO

funcție principal() returnează Unit:
    afișează("Salut, lume!")
    ▶ output
    Salut, lume!

    The proof: same AST, same binary

    Per GRAM-053 and CONV-042, the two files produce byte-identical canonical ASTs and byte-identical binaries:

    bash
    loc dump-ast src/main.lo --canonical > ast-en.json
# ... after switching to RO ...
loc dump-ast src/main-ro.lo --canonical > ast-ro.json
diff ast-en.json ast-ro.json
# (no output)

loc build src/main.lo    --target=x86_64 -o hello-en
loc build src/main-ro.lo --target=x86_64 -o hello-ro
cmp hello-en hello-ro
# (no output)
    Verified promise

    No output from diff and no output from cmp. That is the promise of Lingua Omnibus, verified end-to-end.

    Chapter 04

    Your language, your code

    The #lingua: directive

    Every file starts with #lingua: XX where XX is an ISO 639-1 code, per LEX-090.

    LO
    #lingua: FR
#lingua: DE
#lingua: ES
#lingua: JA
#lingua: RO

    If the directive is missing, the compiler tries to auto-detect (LEX-100). If detection is ambiguous, it fails and asks for an explicit directive (LEX-103).

    One program, six languages

    A complete program that computes the sum of numbers 1 through N:

    🇬🇧 EN
    #lingua: EN
function sum_to(n: Integer) returns Integer:
    var total = 0
    var i = 1
    while i <= n:
        total = total + i
        i = i + 1
    return total

function main() returns Unit:
    print(sum_to(10))
    🇷🇴 RO
    #lingua: RO
funcție suma_până_la(n: Întreg) returnează Întreg:
    variabilă total = 0
    variabilă i = 1
    cât timp i <= n:
        total = total + i
        i = i + 1
    returnează total

funcție principal() returnează Unit:
    afișează(suma_până_la(10))
    🇯🇵 JA
    #lingua: JA
関数 合計まで(n: 整数) 返す 整数:
    変数 合計 = 0
    変数 i = 1
    i <= n の間:
        合計 = 合計 + i
        i = i + 1
    返す 合計

関数 メイン() 返す Unit:
    表示(合計まで(10))

    All three produce 55 and compile to byte-identical binaries.

    Chapter 05

    Variables and types

    var and const

    🇬🇧 EN
    #lingua: EN

var count = 0              // mutable
const MAX = 100            // immutable
var name: String = "Ana"   // explicit type

    Primitive types

    TypeDescription
    Integersigned 64-bit by default (exact widths finalized in SPEC-03)
    Float64-bit IEEE 754
    Booltrue / false
    StringUTF-8, immutable
    Charone Unicode scalar
    Byteone byte (0–255)
    Unitthe "no meaningful value" type

    Inferred types

    Type annotations are optional when the literal determines the type:

    🇬🇧 EN
    var x = 42              // x: Integer
var y = 3.14            // y: Float
var s = "hello"         // s: String
var b = true            // b: Bool

    Type errors

    🇬🇧 EN
    var x: Integer = "hello"   // error
    ▶ error (in your language, per CONV-074)
    error[E0300]: type mismatch
 --> main.lo:2:18
  |
2 | var x: Integer = "hello"
  |                  ^^^^^^^ expected Integer, found String

    Error messages are produced in your language by the active language pack, per CONV-074.

    Chapter 06

    Functions

    Defining functions

    🇬🇧 EN
    function add(a: Integer, b: Integer) returns Integer:
    return a + b

    If the return type is omitted, it defaults to Unit per GRAM-037.

    Recursion

    A factorial function in three languages, producing the same machine code:

    🇬🇧 EN
    function factorial(n: Integer) returns Integer:
    if n <= 1 then:
        return 1
    else:
        return n * factorial(n - 1)
    🇷🇴 RO
    funcție factorial(n: Întreg) returnează Întreg:
    dacă n <= 1 atunci:
        returnează 1
    altfel:
        returnează n * factorial(n - 1)
    🇯🇵 JA
    関数 階乗(n: 整数) 返す 整数:
    もし n <= 1 ならば:
        返す 1
    そうでなければ:
        返す n * 階乗(n - 1)

    factorial(5) returns 120 in all three. The binaries are byte-identical.

    Chapter 07

    Control flow

    if / else

    🇬🇧 EN
    if age >= 18 then:
    print("adult")
else:
    print("minor")
    The then keyword is required

    GRAM-035 requires then after the condition. It documents where the condition ends and the body begins — which helps RTL and CJK packs. Writing if x: without then is a compile error.

    while

    🇬🇧 EN
    var i = 0
while i < 10:
    print(i)
    i = i + 1

    for

    🇬🇧 EN
    for item in [1, 2, 3, 4, 5]:
    print(item)

    match

    🇬🇧 EN
    match value:
    0:
        print("zero")
    1:
        print("one")
    _:
        print("many")

    Maps

    🇬🇧 EN
    var ages = Map<String, Integer>{
    "Ana": 25,
    "Ion": 30
}
var ana_age = ages["Ana"]             // 25

    Option — no null surprises

    🇬🇧 EN
    var maybe: Option<Integer> = Some(42)
var nothing: Option<Integer> = None()

match maybe:
    Some(v):
        print("got ", v)
    None:
        print("nothing")

    There is no bare null. The type system forces you to handle None explicitly.

    Chapter 09

    Errors without exceptions

    The Result type

    🇬🇧 EN
    function divide(a: Integer, b: Integer) returns Result<Integer, String>:
    if b == 0 then:
        return Err("division by zero")
    else:
        return Ok(a / b)

    The ? operator (statement-tail only)

    🇬🇧 EN
    function safe_divide(a: Integer, b: Integer) returns Result<Integer, String>:
    var q = divide(a, b)?
    return Ok(q)

    ? propagates the error early. Per GRAM-024, it only works as the last sub-expression of a return statement — the compiler rejects misplaced uses.

    Handling errors

    🇬🇧 EN
    match divide(10, 0):
    Ok(v):
        print("result: ", v)
    Err(e):
        print("error: ", e)
    No try/catch. No unchecked exceptions.

    Every error is a type. The compiler guarantees you handle it.

    Chapter 10

    Effects — I/O done explicitly spec-preview

    A preview of SPEC-05. The syntax is stable; the details are under RFC.

    🇬🇧 EN
    function read_config(path: String) returns Result<String, Error>
    with [IO, Filesystem]:
    var content = read_file(path)?
    return Ok(content)

    The with [IO, Filesystem] clause declares at compile time that this function will touch the file system. A function without Filesystem effect cannot call read_file.

    This means: you can see, from the signature, exactly what side effects a function has. No hidden global state.

    Available effects:

    • IO
    • Database
    • Network
    • Filesystem
    • Quantum
    Chapter 11

    Your first LinguaDB spec-preview

    Define a schema

    🇬🇧 EN
    create table Visitors if_not_exists (
    id      Integer primary_key auto_increment,
    name    String(100) not_null,
    email   String(255) not_null unique,
    age     Integer,
    created Time default NOW()
)
    Verified at compile time

    The schema is checked at compile time. If you later try to insert into a column that doesn't exist, the compiler refuses — not the runtime.

    Insert a row

    🇬🇧 EN
    insert into Visitors (name, email, age)
    values ("Ana Ionescu", "ana@example.com", 25)

    Query

    🇬🇧 EN
    var adults =
    select name, email
    from Visitors
    where age >= 18
    order by name ascending

for v in adults:
    print(v.name, " <", v.email, ">")

    select returns typed rows. v.name is a String; v.email is a String. No ORM, no reflection, no runtime type errors.

    Chapter 12

    A taste of quantum spec-preview

    A Bell pair

    🇬🇧 EN
    function bell() returns Result<Tuple<Bool, Bool>, QuantumError>
    with [Quantum]:
    quantum:
        qubit q0, q1
        hadamard(q0)
        cnot(q0, q1)
        var r0 = measure(q0)
        var r1 = measure(q1)
    return Ok((r0, r1))

    Possible results: (true, true) or (false, false). Never (true, false) — entanglement guarantees it.

    The compiler enforces the no-cloning theorem

    🇬🇧 EN
    qubit q
var a = q              // error: cannot copy a qubit
var b = q              // error: cannot copy a qubit
    ▶ error
    error[E0900]: qubit is linear, cannot be duplicated
 --> main.lo:3:9
  |
3 | var a = q
  |         ^ moved here; a qubit can only be used once
    Linear types as a theorem

    The type Qubit is linear — it can only be consumed once. This is not a runtime check. It is a compile-time theorem.

    Chapter 14

    The package manager (lopm)

    Add a dependency

    bash
    lopm add math-advanced

    This edits loc.toml:

    tomlloc.toml
    [dependencies]
"math-advanced" = "^1.2.0"

    Federated registries

    tomlloc.toml
    [registries]
default = "https://my-company.example/lopm"
mirror  = "file:///srv/lopm-mirror"

[registries.policy]
fallback = ["default", "mirror"]
offline  = false
    No official registry

    There is no mandatory "official" registry per CONV-080. Federated by design.

    Offline mode

    bash
    lopm vendor                   # copies all deps into vendor/
lopm install --vendor         # installs with no network

    This is Principle 6 in action: your build never breaks because a registry is down.

    Testing (lotest)

    A test file

    🇬🇧 ENtests/add_test.lo

function test_add_positive():
    assert_eq(add(2, 3), 5)

function test_add_negative():
    assert_eq(add(-2, -3), -5)

    running 3 tests
test test_add_positive ... ok
test test_add_negative ... ok
test test_add_zero    ... ok

    🇷🇴 ROtests/add_test.lo

funcție test_adunare_pozitive():
