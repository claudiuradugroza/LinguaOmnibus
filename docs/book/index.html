Introduction

Lingua Omnibus (LO) is a universal, multilingual, open-source programming language. It compiles natively to x86_64, ARM64, RISC-V, PowerPC, WebAssembly, and quantum backends (OpenQASM 3.0).

Getting Started

#lingua: EN
function main() returns Unit:
    print("Hello, world!")
    return ()
