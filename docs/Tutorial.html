2. Variables and Types / Variabile si Tipuri

LO supports exact-width integer types, floats, booleans, strings, chars, bytes, and quantum types.

LO suporta tipuri intregi cu latime exacta, float-uri, booleani, string-uri, char-uri, byte-uri si tipuri cuantice.

#lingua: EN
function main() returns Unit:
    var x: int32 = 42
    var y: f64 = 3.14
    var s: string = "hello"
    var b: bool = true
    var arr: [int32] = [1, 2, 3]
    print(x)
    return ()

3. Functions / Functii

Functions are declared with function keyword, parameters with colon, and return type with returns.

Functiile se declara cu cuvantul function, parametrii cu doua puncte, si tipul de return cu returns.

#lingua: EN
function add(a: int32, b: int32) returns int32:
    return a + b

function main() returns Unit:
    var res = add(5, 3)
    print(res)
    return ()

4. Control Flow / Flux de control

LO supports if/else, while, for, and match statements.

LO suporta if/else, while, for si match.

If/Else

#lingua: EN
function main() returns Unit:
    var score: int32 = 85
    if score >= 90 then:
        print("A")
    else:
        if score >= 80 then:
            print("B")
        else:
            print("C")
    return ()

While

#lingua: EN
function main() returns Unit:
    var i: int32 = 0
    var sum: int32 = 0
    while i <= 10:
        sum = sum + i
        i = i + 1
    print(sum)
    return ()

5. Memory and Ownership / Memorie si Proprietate

LO uses single ownership for non-Copy values. Borrowing uses shared and mutable references.

LO foloseste proprietate unica pentru valori non-Copy. Imprumutul foloseste referinte shared si mutable.

#lingua: EN
var s1 = String("hello")
var s2 = s1          # s1 moved to s2
var s3 = s2.clone()  # explicit clone
var x = 42
var r1 = x           # copy (int is Copy)
var r2 = x           # still valid
return ()

6. Quantum Programming / Programare cuantica

LO supports quantum computing via quantum blocks that compile to OpenQASM 3.0.

LO suporta computatie cuantica via blocuri quantum care compileaza la OpenQASM 3.0.

#lingua: EN
quantum:
    var q = alloc_qubit()
    var r = measure(q)
    print(r)
return ()

SPEC-02: Grammar

Reference EBNF grammar over keyword slots. Unified AST across all languages.

# Significant indentation (GRAM-010 to GRAM-015)
# Expression precedence table (GRAM-020)
# No chained comparisons (GRAM-022)
# Unified AST node kinds (GRAM-050)
# AST identity test (GRAM-053)
# loc dump-ast --canonical (GRAM-054)

SPEC-03: Type System

Primitive types with exact bit widths, generics, linear types for qubits.

int8, int16, int32, int64, int128
uint8...uint128, f32, f64, bool, char, byte, unit, string
qubit, qreg, qcircuit, qstate (linear)
Option, Result, Map, Array, Tuple, Function

SPEC-04: Memory Model

Single ownership, borrowing, lifetimes, stack/heap, drop semantics, optional GC.

# Move semantics
var s1 = String("hello")
var s2 = s1  # s1 moved
# Borrowing
var x = 42
var r1 = x  # copy (int is Copy)
# Drop: exactly once per owner
# Stack overflow guard (1 MiB default)

SPEC-05: Effects and Concurrency

Effect classes: IO, DATABASE, NETWORK, FILESYSTEM, QUANTUM. Async/await, spawn.

function read_file() returns string with [IO]:
    return "data"

async function fetch() returns string:
    var data = await http_get("url")
    return data

function main() returns Unit:
    var h = spawn(|| { return 42 })
    var r = h.join()

SPEC-06: LIR (Intermediate Representation)

Universal semantic form. Text + binary. Independent version (SemVer).

lir 1.2.0 module main entry: %r1 = const.str Hello world ret unit

SPEC-07: Backends

LLVM, WASM, ARM64, RISC-V, PowerPC, OpenQASM 3.0.

Targets: x86_64, arm64, riscv64, powerpc64, wasm32, qasm3

Integrated ACID database. Create, insert, select, update, delete.

db insert into users (id, name) values (1, Alice)
