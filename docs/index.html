The Proof

One program. Three languages. One binary.

Click a language tab. The code changes. The binary doesn't. This is verified on every commit by conformance/gram/050/fib-en-ro.lo.

fib-en.lo
#lingua: EN function fib(n: Integer) returns Integer: if n <= 1 then: return n else: return fib(n - 1) + fib(n - 2) function main() returns Unit: print(fib(10))
$ loc build fib-en.lo --target=x86_64 -o fib-en ✓ Language detected: English (EN) ✓ LIR compilation complete · 0 errors ✓ Backend: native x86_64 $ loc build fib-ro.lo --target=x86_64 -o fib-ro ✓ Language detected: Romanian (RO) ✓ LIR compilation complete · 0 errors ✓ Backend: native x86_64 $ cmp fib-en fib-ro ✓ Binaries are byte-identical. $ ./fib-en 55 $ ./fib-ro 55

Every modern programming language is, in essence, a dialect of English. if, else, function, return — 40+ keywords, one natural language.

Non-English speakers must learn two languages to write one program. This is not a technical limit. It is a historical accident that has been accepted for 70 years.

Architecture

Three layers. One semantics.

Languages touch only layer 1. Layers 2 and 3 never see natural language — they see the unified AST and the LIR. That's why adding a language never requires changing the compiler.

LAYER 01
Multilingual Frontend
One parser per natural language, each producing the same unified AST. A language pack is pure data — no compiler changes needed.
English Română Français Deutsch 日本語 + 25 more
LAYER 02
Universal Semantic Core
The LIR (Lingua Intermediate Representation) is language-agnostic and architecture-agnostic. Type inference, constant folding, DCE — all happen here, all identically.
Type inference LIR emitter Verification Formal proofs
LAYER 03
Multi-Target Backend
Native code for every architecture. Same LIR in, byte-identical binaries out — regardless of which natural language the source was written in.
x86_64 (C) x86_64 (asm) OpenQASM 3.0 WASM ARM64 RISC-V
