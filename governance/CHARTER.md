# Lingua Omnibus Foundation Charter

## Purpose
The Lingua Omnibus Foundation stewards the Lingua Omnibus programming language specification and ecosystem as a free, open, community-governed project.

## Governance Model
- No BDFL (Principle 9).
- RFC process is public (SPEC-13).
- Maintainers are elected.
- Explicit right to fork is guaranteed.

## Scope
The foundation governs the specification set (SPEC-00 … SPEC-13), the conformance suite, and the trademark.

## License
All specification text and reference implementation code are released under the Apache 2.0 license (Principle 10).
