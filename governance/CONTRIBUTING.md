# Contributing

Thank you for contributing to Lingua Omnibus!

## How to contribute
1. Read SPEC-00 (Conventions & Terminology).
2. Propose changes via the RFC process (SPEC-13, governance/rfcs/).
3. Every normative rule MUST carry a rule identifier and a conformance test (CONV-010, CONV-012).
4. Language packs are pure data — add a new language under langpacks/{iso}/ (CONV-061).
